# Ejercicios básicos de React

Proyecto Vite + React + TypeScript con los siete ejercicios de "React desde cero". No necesita backend ni variables de entorno.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # verifica los tipos y genera la versión de producción
```

Cada ejercicio está en su archivo (`src/Ej1.tsx` a `src/Ej7.tsx`) y `src/App.tsx` los muestra todos con su título.
